# Hablapp 0.4.0

## Prompts más claros

- Prompt engineer convierte el dictado en un único pedido para otra IA, conservando la tarea original, prioridades, datos y condiciones.
- Reescritura y revisión editorial independiente para reducir repeticiones. Si una solicitud falla o no supera los controles, se conserva el dictado y no se envía Enter automáticamente.
- Mejora opcional con tu propia API de OpenAI, desactivada por defecto. Configúrala en **Ajustes › Mejora de prompts**. La clave se guarda en el Llavero de macOS; el consumo corresponde a tu cuenta de API.
- Contexto de pantalla para corregir nombres y términos cercanos. Es efímero: no se guarda en el historial ni se envía como texto de ventana a la API. Puedes desactivarlo en **Ajustes › Datos y privacidad**.
- Se conservan las reglas por aplicación y los transforms personalizados al actualizar.

## Actualizaciones y apoyo al proyecto

- Búsqueda automática activada por defecto, respetando las preferencias anteriores. Consulta al iniciar y al reactivar el Mac, como máximo una vez al día.
- Aviso visible cuando hay una versión nueva. Tú decides cuándo instalar y reiniciar.
- Corregido un fallo que impedía instalar al aceptar el diálogo de búsqueda manual.
- GitHub Sponsors disponible en el menú, la barra lateral y **Ajustes › Acerca de**.
- Recordatorio opcional de donación después de siete días y veinte dictados. Puedes posponerlo treinta días, desactivarlo o indicar que ya apoyas el proyecto.

## Descargar o actualizar

Descarga **hablapp.zip**, descomprímelo y mueve Hablapp a Aplicaciones. Si ya usas la app, abre **Ajustes › Acerca de**, busca actualizaciones y pulsa **Actualizar y reiniciar**. Si el diálogo de una versión anterior no inicia la instalación, vuelve a Acerca de y usa el botón de actualización disponible allí.

Requiere macOS 26 y Apple Silicon. La transcripción de voz continúa siendo local. La app sigue sin notarización de Apple; la primera apertura puede requerir autorizarla en Privacidad y seguridad.
