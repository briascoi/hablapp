# Hablapp 0.4.1

## Nuevos atajos de transforms

- Los transforms sobre texto seleccionado se activan con **Control + Command + 1 a 9**, según su posición en la lista.
- **Option + número** queda libre para escribir caracteres como `@` y `#` según la distribución de tu teclado.
- El interruptor **Atajos de teclado**, en Transforms, permite desactivar estas combinaciones y conservar los transforms automáticos por aplicación. El interruptor general de Transforms sigue desactivando ambas funciones.
- Los atajos sólo se capturan cuando el motor está libre y existe un transform en esa posición. Mantener una tecla pulsada no vuelve a ejecutar el transform por repetición automática.
- La página Transforms, las tarjetas y la ayuda de atajos muestran las nuevas combinaciones.

## Descargar o actualizar

Desde **Ajustes › Acerca de**, pulsa **Buscar actualizaciones** y luego **Actualizar y reiniciar**. También puedes descargar **hablapp.zip**, descomprimirlo y reemplazar la app en Aplicaciones.

Requiere macOS 26 y Apple Silicon. Hablapp sigue siendo gratuita y de código abierto. La transcripción y los transforms locales usan tu Mac; Prompt engineer continúa siendo opcional y utiliza tu propia cuenta de API de OpenAI.

Esta versión conserva el certificado de firma anterior y todavía no está notarizada por Apple. Al usar la mejora por API después de actualizar, macOS puede volver a pedir acceso a la clave guardada en el Llavero. Puedes autorizar esta versión con **Permitir siempre** en el diálogo de macOS.
